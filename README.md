# Cue Releases

Auto-update feed for [Cue](https://github.com/adichaa/cue).

## Installing

Download the latest `.dmg` from [Releases](https://github.com/adichaa/cue-releases/releases).

## Auto-updates

Cue checks for updates automatically via [Sparkle](https://sparkle-project.org). The feed is served from this repo via GitHub Pages at:

```
https://adichaa.github.io/cue-releases/appcast.xml
```
